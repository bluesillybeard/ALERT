# Advanced Line Effect Rendering Technology

So basically this is a scuffed line renderer (despite the fact that I have literally called it advanced lol) with some kind of game attached to it.

I started it for the 2026 Mines game dev club october game jam.

## MINIMUM REQUIREMENTS
- OpenGL 4.3
    - In hindsight I should have used sokok or bgfx or anything else so macos support could have been possible. Oh well.
- Idk like 1gb of vram or something
- This app does absolutely eat through PCIE bandwidth so, if you have something dumb like a 5090 through a x1 PCIE slot, well I wish you the best.
